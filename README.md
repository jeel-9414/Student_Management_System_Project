# Student Management System 📱

An Android application developed using Kotlin and SQLite to manage student records.

## Features
- Student Registration and Login
- Student Profile Management
- CRUD Operations
- Attendance Management
- Fee Management
- Academic Result Management

## Technologies Used
- Kotlin
- Android Studio
- SQLite
- XML

## Purpose
Developed as an academic project to explore Android application development and database management.
