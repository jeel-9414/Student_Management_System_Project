# Student Management System 📱

An Android application developed using Kotlin and SQLite to manage student records and academic activities.

## Features
- Student registration and login
- Student profile and record management
- Attendance management
- Fee management
- Academic result management

## Technologies Used
- Kotlin
- Android Studio
- SQLite
- XML
